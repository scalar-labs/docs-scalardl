# 監視の概要

import DocCardList from "@theme/DocCardList";
import TranslationBanner from '/src/components/_translation-ja-jp.mdx';

<TranslationBanner />

監視は、ScalarDL デプロイメントの健全性とパフォーマンスを維持するために不可欠です。このセクションでは、Kubernetes クラスター環境での ScalarDL の監視に関するガイダンスを提供します。これにはシステムの可用性の確認、時系列メトリックの収集、および監視ダッシュボードを通じたログの表示が含まれます。

:::note

ScalarDL はデータ管理と Function 機能に ScalarDB を使用するため、デプロイメントで ScalarDL と ScalarDB の両方を使用する場合があります。このような場合は、ScalarDL に加えて ScalarDB も監視する必要があります。

:::
